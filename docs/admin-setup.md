# 管理后台：初始化、使用与验收

## 提取记录（2026-11-17）

导航「提取记录」（`/admin/history`）查看所有用户现有的字幕/转写历史，支持搜索、状态筛选和分页。用户以邮箱展示，可查看文稿或打开原视频；不提供删除或重新执行功能。范围与前台历史一致，已隐藏和过期记录不展示。详见 [验证记录](./admin-history-verification.md)。

## 套餐额度管理（2026-11-17）

导航「套餐额度」（`/admin/limits`）单独管理免费、月卡、年卡的五项功能额度。普通管理员只读，超级管理员填写整数后核对变更，再确认保存；额度立即对已有用户和本期生效，已用量与预占保留。降低额度可能阻止新任务提交，确认页会提示影响。价格仍在「会员价格」管理。详见 [额度管理验收](./admin-limits-verification.md)。

## 会员价格管理（2026-11-17）

后台导航「会员价格」（`/admin/pricing`）允许普通管理员查看月卡/年卡价格，超级管理员可输入元金额，经原价/新价确认后保存。改价留审计记录；冲突时须刷新重确认。前台可见定价页 30 秒内同步，付款前校验价格，不修改旧订单或已有权益。详见 [价格管理验收](./admin-pricing-verification.md)。

管理后台入口：`http://localhost:8000/admin/login`。后台账号与网站注册用户独立，可以在同一浏览器同时登录。

## 首次设置

后端启动会增量创建后台表与注册用户启停字段，不会生成默认管理员或覆盖已有账号。首次使用需要在项目的 `backend` 目录执行：

```powershell
$env:PYTHONIOENCODING='utf-8'
.venv/Scripts/python -m app.admin_auth bootstrap --username admin
```

按提示输入两次新密码，输入不会显示。密码为 8–128 个字符，不能全为空白或与登录名相同。初始化成功后，使用 `admin` 和刚设置的密码登录后台。已有后台账号时，此命令会拒绝重复初始化，不会覆盖原密码。

遗忘后台密码时，在服务器本机执行：

```powershell
.venv/Scripts/python -m app.admin_auth reset-password --username admin
```

该命令隐藏输入新密码并撤销该后台账号的全部会话。不会更改账号角色、启用状态或前台用户密码。不提供公共后台注册或通过网站邮箱找回后台密码的入口。

## 两类管理权限

| 能力 | 普通管理员 | 超级管理员 |
|---|---|---|
| 查询注册用户、查看详情、禁用/启用 | 支持 | 支持 |
| 新增/编辑后台账号、角色、启用状态、重置后台密码 | 无权访问 | 支持 |
| 修改自己的后台密码、退出 | 支持 | 支持 |

不能禁用当前登录的后台账号，且必须保留至少一位启用的超级管理员。角色变动、密码重置和禁用会使对应账号的旧后台会话失效。后台会话默认 8 小时，通过 `ADMIN_SESSION_HOURS` 配置；修改后重启后端生效。

## 注册用户管理

- 按邮箱、昵称或 ID 搜索，按账号状态和邮箱验证状态筛选，每页 20 条。搜索条件与页码保存在当前页面 URL，可刷新或返回恢复。
- 详情展示基础资料、注册时间、验证状态、启停状态、当前会员和到期时间；不展示密码摘要、会话或邮件凭证。
- 禁用需要确认，可填写原因。禁用后撤销全部前台登录会话及未使用的邮件验证/找回链接，不能通过密码登录或旧邮件链接重新登录。
- 重新启用不恢复旧会话、邮件链接，也不自动验证邮箱；用户需要重新登录，待验证账号仍需完成邮件验证。
- 会员、订单、用量和历史保留，会员有效期继续按原规则计算。已经接受的任务继续处理和结算，已付款旧单照常入账，账号保持禁用。
- 账号禁用不封禁 IP；退出后仍按原游客规则处理公开下载。首版没有删除注册用户、代登录、修改邮箱或手工改会员/额度。

后台账号管理使用独立登录名、显示名称、角色、状态和密码；登录名创建后不修改。重置后台密码不会更改普通注册用户的密码。

## 运行与数据

后台接口位于 `/api/admin/*`，后台 Cookie 为 `freevideo_admin`，路径 `/api/admin`；前台 Cookie 与身份状态保持独立。后台退出或过期不使前台账号退出，前台退出不打断后台页面。

数据表为 `admin_users`、`admin_sessions`、`admin_account_guard`、`admin_audit_logs`；注册用户新增状态和禁用信息。管理写操作记录操作者、目标和时间，审计不保存密码、哈希或登录令牌；本版没有审计查询页面。

初始化、密码恢复、角色及状态操作共用事务锁，防止并发操作导致没有可用超级管理员。权限由后端复核，隐藏前端菜单不作为权限依据。

## 测试与验收

权限、并发、用户禁用与邮件等后端测试在独立 MySQL 测试库运行，页面模拟检查和真实测试后端浏览器检查分别记录，见 [后台验证记录](./admin-verification.md)。

人工验收：

1. 初始化首位超级管理员并登录 `/admin/login`，确认只出现「注册用户」「后台账号」两个管理模块。
2. 搜索一个已注册邮箱，查看资料；禁用该用户后，原前台设备退出、登录被拦截。重新启用后可重新登录，会员及订单保留。
3. 创建普通管理员，用另一浏览器登录，确认其只能管理注册用户，不能直接访问后台账号管理接口。
4. 编辑后台账号、重置密码或禁用，确认对应旧后台会话失效；不能禁用自己或移除最后一个可用超级管理员。
5. 同一浏览器同时登录前台和后台，分别退出，确认身份互不影响；在手机检查搜索、筛选、详情及确认弹窗。

首次部署需要构建前端并重启后端加载新增路由和迁移。月卡 0.50 元真实支付测试配置单独保留，本后台不调整支付配置。

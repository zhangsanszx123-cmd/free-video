## 人工验收清单

启动：`cd backend && .venv/Scripts/python -m uvicorn app.main:app --host 0.0.0.0 --port 8000`，访问 http://127.0.0.1:8000 。

- [ ] 未登录点击导航「批量提取」或「AI 总结」→ 留在当前页弹出登录窗，提示“请先登录后使用该功能”；关闭弹窗仍在原页
- [ ] 弹窗切换到「注册」注册新用户 → 自动登录并进入刚才点击的页面，导航显示头像与昵称
- [ ] 导航「登录」「注册」直接打开对应 Tab 的弹窗；Esc、右上角关闭、点击遮罩均可关闭
- [ ] 首页粘贴链接，未登录点击「AI 视频总结」→ 弹窗登录后原地切换到 AI 视图并自动总结
- [ ] 头像菜单 →「个人中心」：修改昵称后导航即时更新
- [ ] 用另一浏览器（或手机）登录同一账号 → 个人中心「登录设备」出现 2 条，可下线另一台
- [ ] 修改密码 → 回到首页并弹出登录窗提示重新登录，旧密码无法登录
- [ ] 打开两个标签页，在一个标签页退出 → 另一个停留在个人中心的标签页自动回到首页
- [ ] 注销账号（输入密码与用户名）→ 回到首页提示“账号已注销”，无法再登录
- [ ] 备用页面 /login、/register 仍可直接访问使用
- [ ] 未登录时单条视频解析、下载、字幕提取照常可用
- [ ] 手机宽度：菜单中「登录」「免费注册」打开弹窗且不溢出屏幕；登录后显示账号卡片与「退出登录」

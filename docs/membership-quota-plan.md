# 会员、语音识别额度与任务历史方案

## 状态

2026-11-11：用户确认后实施。增量表在应用启动时自动创建；不开发在线支付和管理后台页面，先提供服务器本机管理命令。

## 已确认规则

| 套餐 | 价格 | 每月语音识别额度 |
|---|---|---|
| 免费 | 0 元 | 30 分钟（1800 秒） |
| 月卡 | 19.9 元/月 | 10 小时（36000 秒） |
| 年卡 | 99 元/年 | 30 小时（108000 秒），按月发放 |

- 所有套餐按北京时间每月 1 日 00:00 重置，未使用额度不结转；年卡不一次性发放全年额度。
- 任务记录及转录文本从提交起保存 30 天；视频、音频和临时文稿文件沿用 30 分钟 TTL。
- 仅调用语音识别扣时长；视频下载、提取平台现成字幕免费。
- 套餐价格、时长需要持久化并预留后台管理能力；页面、鉴权和扣量读取同一份服务端配置。
- 页面参考用户提供的截图：账号下拉面板展示会员和额度，提供执行中任务与历史任务入口；保留自动首字母头像，不提供修改头像功能。

## 扩展前现状与本次接入点

- `account_store.py` / `backend/sql/schema.sql` 已使用 MySQL 原生 SQL 管理用户与会话；沿用 PyMySQL，不增加 ORM。
- 扩展前 `transcriptions.py` 任务仅在内存中，以签名匿名会话为 owner，批量转录同样如此；现已将登录用户的转录任务绑定为 `user:<id>`，持久化历史与文稿，单进程内存队列继续负责执行。
- 扩展前单条转录允许游客，批量转录未把登录账号传入任务；现已为单条 ASR 校验登录身份，单条及批量均使用认证账号扣量，状态和导出同样按账号校验。现成字幕与下载继续允许游客使用。
- `asr_ledger.py` 的 JSON 账本控制全站供应商成本预算，包含分段结算和不确定请求恢复。继续保留该保护，不把它当作用户会员额度。
- 平台字幕与 ASR 需要共用账号任务记录，但仅进入 ASR 时预占用户时长。批量调用、短链归一化复用、失败重试均需经过同一额度服务。
- 已同步调整免费体验/演示版文案；定价页保留原有玻璃卡片与深色金边年卡风格，突出转录时长，价格和额度读取数据库配置。

## 建议数据结构

1. `membership_plans`：套餐代码、配置修订号、价格（整数分）、每月额度（整数秒）、有效月数。不在 Vue 组件散落写死金额；现阶段通过本机命令修改，供后续后台复用。
2. `user_memberships`：用户、套餐版本、开通与到期时间、来源。保存权益快照，避免改套餐后静默改变已开通用户权益。
3. `user_quota_periods`：用户、会员归属、本期起止时间、额度快照、已使用和预占秒数；唯一约束避免重复发放。
4. `transcription_records`：用户、任务、规范视频指纹、URL、来源、标题/平台/封面、视频时长、阶段、结果、错误及时间。文本保留 30 天；批次子任务进入同一历史列表，批次本身仍为内存编排。视频与音频不入库。
5. `quota_reservations` / `quota_events`：任务、本期额度、预占秒数、规范指纹、结算状态和幂等操作流水；移出历史不删除额度账本、不返还已消耗时长。
6. 本期无支付订单和支付接口；管理员配置与开通命令不对普通用户开放。

## 额度处理

- 服务端核实音频时长，按整秒向上取整；分段输入按完整音频统一口径计算用户额度，供应商成本账本仍按供应商口径结算。
- 用数据库事务和行锁完成额度检查及预占；云识别在事务外执行，避免长时间锁表。
- 用户额度和全站预算均预占成功，才允许提交云识别。任一预占失败须补偿释放已成功的预占；数据库不可用时停止新的 ASR 提交。
- 同一用户复用已有结果、轮询、复制和导出不重复扣量；前端传入的用户标识、套餐、时长和金额不作为扣量依据。
- 成功结算一次；明确未提交或被云端拒绝时释放；状态不明时保留预占并显示“待核对”，禁止自动重复提交。
- 部分分段成功、整体无可用结果时释放用户时长；已发生的供应商成本仍记录在全站账本。不自动重新提交整条视频。
- 任务预占绑定具体额度周期；跨周期完成仍结算原预占，不能扣入新周期。重启对账且不自动重发付费请求。
- 会员到期、升级、续费与免费额度切换均要有明确规则；不能在过期或配置变动时隐式发放第二份额度。

## 页面与接口建议

- 公开套餐查询接口供定价页使用；登录后的会员与额度接口供个人中心和账号菜单使用。
- 个人中心新增会员及额度分区：套餐、有效期、周期起止、总额度、已用/预占/可用、升级入口。
- 历史任务分页查询、搜索、状态筛选、详情与 TXT/SRT 导出；执行中任务提供当前阶段。全部按账号鉴权，跨设备可见。
- 已删除或过期的临时媒体标记为不可用；不把历史封面/播放直链包装成永久可下载资源。
- 未登录用户触发 ASR 时打开现有登录弹窗，登录后继续动作；有平台字幕时不要求为扣量额外登录。

## 已落实的边界规则

1. 所有套餐自然月重置；会员有效期按开通日加 1/12 个日历月，月底按目标月最后一天处理。有效期内每个自然月获得对应额度，不按天折算。
2. 人工开通用付费月额度替换本月总额度，保留已使用与预占时长。人工 `grant` 仍只给免费用户开通；2026-11-13 起在线支付支持同档续费顺延与月卡升级年卡（见 [zpay-setup.md](./zpay-setup.md)）。
3. 付费会员到期即恢复免费额度，保留本月已使用和预占，防止到期后额外赠送额度。
4. 修改套餐后页面立即展示最新价格；已开通付费会员保留开通时权益快照。已生成免费月额度不追溯修改，下个自然月使用最新配置。
5. ~~不接入支付协议~~ 2026-11-13 已接入 ZPAY 支付宝支付，见 [zpay-setup.md](./zpay-setup.md)。
6. 移出历史仅隐藏展示，原任务复用不再次扣量；30 天到期后清理文本及任务记录。额度账本保留以便核对，不包含转录正文。
7. 状态不明请求保留预占；跨月未决预占也会暂占当月可用量，避免通过跨月或重启绕过。不自动重发收费请求，需管理员核对。

## 本机管理（在 backend 目录运行）

```powershell
# 读取当前套餐；数据库配置来自 backend/.env
.venv/Scripts/python -m app.membership plans
# 给已有免费用户人工开通会员（不执行支付）
.venv/Scripts/python -m app.membership grant 用户名 monthly
.venv/Scripts/python -m app.membership grant 用户名 yearly
# 修改后续套餐价格/额度：价格单位为分，时长单位为秒
.venv/Scripts/python -m app.membership configure monthly --price-cents 1990 --monthly-seconds 36000
.venv/Scripts/python -m app.membership configure yearly --price-cents 9900 --monthly-seconds 108000
.venv/Scripts/python -m app.membership configure free --price-cents 0 --monthly-seconds 1800
```

不向前端开放这些写操作。运行测试时只配置 `MYSQL_DATABASE=freevideo_test`，不要把测试库清理脚本对准正式库。未来管理后台可复用 `configure` 与 `grant`，仍需补齐管理员认证、操作审计和升级/续费规则。

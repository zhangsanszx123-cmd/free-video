# FreeVideo 需求分析文档

## 2026-11-15 游客限制：只可免费下载 2 个视频（用户确认并实现）

- 未登录用户（游客）只能**解析并下载 2 个不同的视频链接**（视频、MP3 均可，同一链接重复解析/下载不再计次）；字幕提取、文稿、语音识别、批量、AI 总结、翻译等**其余功能全部需要登录**。登录用户的下载不限次数、不扣额度。
- 计次口径（用户选择）：按链接计，成功解析 1 个新链接算 1 次，解析失败不计；游客必须先解析再下载（直接调用下载接口会被拒）。
- 识别方式（用户选择）：签名 Cookie + IP 双重记录，任一达到 2 个链接即拦截新链接，清 Cookie 无法重置；同一出口 IP 的多人共享这 2 个名额，登录即可解除。次数**永不重置**。
- 游客的 2 个视频**时长在该浏览器首次登录或注册时，从当月「视频转文字时长」额度中补扣**（最多扣到额度用完，只补扣一次；同一浏览器之后登录其它账号不会再次补扣）。登录/注册成功后提示已计入的分钟数。
- 超限提示：解析返回 403 `GUEST_LIMIT`，前端自动弹出登录窗；游客解析后的字幕/文稿区显示「登录后可提取平台字幕与视频文稿」及登录按钮，不再自动请求字幕。取代此前「游客可免费提取平台字幕、单条转写」的约定。

## 2026-11-15 套餐使用上限（用户确认并实现）

- 在语音识别时长额度之外，新增按套餐区分的使用上限，数值持久化在 `membership_plans`（可用 `python -m app.membership configure <plan> --price-cents .. --monthly-seconds .. --ai-monthly-limit .. --batch-max-links .. --asr-max-minutes .. --chat-daily-limit ..` 调整，立即生效，不做快照）：

| 套餐 | AI 视频总结（每周期） | 批量提取（单次链接数） | 单条识别最长 | AI 追问（每天） |
|---|---|---|---|---|
| 免费 | 10 个视频 | 3 条 | 8 分钟 | 1 条 |
| 月卡 | 300 个视频 | 10 条 | 30 分钟 | 10 条 |
| 年卡 | 500 个视频 | 15 条 | 60 分钟 | 20 条 |

- 用户确认的口径：AI 次数**按视频计次**——同一视频在同一周期内的总结（含三种视角）、思维导图、字幕翻译和追问共算 1 个视频，生成失败（无输出、缺字幕需转写、异常）不扣；重置周期与语音识别额度一致（免费从注册日、会员从开通日，北京时间）。批量上限为**单次提交的链接条数**（视频/音频/字幕批量均适用，全局 `MAX_BATCH` 仍为上限）。
- 我建议并经用户选择的补充限制：**AI 追问每天条数**（北京时间 0 点重置，失败退回）与**单条语音识别最长时长按套餐**（`ASR_MAX_DURATION` 默认 3600 秒作为全局硬上限，实际取 `min(套餐, 全局)`，识别前和音轨获取后各校验一次）。追问与时长的数值由用户最终指定：识别 8 / 30 / 60 分钟，追问每天 1 / 10 / 20 条。
- 定价页套餐卡只保留四项使用上限；「视频下载免费 / 逐月重置 / 额度不结转或不叠加 / 文稿导出不扣量 / 保存 30 天」从卡片中移除（规则仍在下方 FAQ 与个人中心说明）。
- 未选择、本轮不做：下载并发/频率限制、下载清晰度按套餐、手机端触控区补齐。
- 超限提示：AI 超限 SSE 返回 error 事件、非流式接口返回 HTTP 403（`AI_QUOTA_EXCEEDED` / `CHAT_QUOTA_EXCEEDED` / `BATCH_LIMIT`），文案引导查看定价页；个人中心额度卡、定价页套餐卡与对比表、批量页均展示对应上限。
- 验证见 [前端审查验证记录](./frontend-audit-verification.md) 末尾「套餐使用上限」。

- 在 `/batch` 的格式选项增加「字幕 SRT · 支持语音识别」，不增加字幕语言选择；沿用现有默认轨道优先级，识别原语音、不翻译。
- 先检查平台字幕；确认无字幕或内容为空时自动使用已配置的收费 ASR。登录访问受限、网络错误不自动转收费识别。开始前明确提示 API 预算消耗，沿用单视频时长、大小、全站预算限制。
- 独立结果面板：空态引导 → 实时逐条阶段与完成统计 → 左侧列表、右侧字幕预览；手机上下排列。成功结果标注平台字幕/自动字幕/语音识别，支持时间戳开关、复制、单条 SRT 下载和复制全部正文。
- 整批结束后用户手动打包成功的 SRT；失败项显示原因，全部失败不提供空 ZIP。预览、复制和打包不会再次收费识别。
- 最多 20 条（以后端配置为准），分享文本提取链接并去重；复用原转写队列、会话归属、预算和规范 URL 去重。并发执行两批，每批顺序处理链接，共最多 10 个未结束批次；超额返回明确提示。
- 浏览器保存最近字幕批次 ID，离开/刷新后在同一会话、同一服务进程内恢复查询，不重新创建收费任务。整批结果从批次结束起保留 30 分钟（可配置）；过期提示并清除浏览器记录，服务重启不恢复任务正文。
- 批量工作台隐藏手机升级浮层，避免遮挡费用说明与主要操作。保留视频、音频原有下载流程。
- 该扩展取代 F8 中「首期不增加批量转写」的旧范围限制。验证步骤见 [批量字幕验收记录](./batch-subtitles-verification.md)。

## 1. 背景与目标
用户有把视频保存到本地的需求，但常遇到：
- 平台不提供下载功能；
- 下载不便：不支持批量、有次数/清晰度限制、带水印；
- 手机上难以下载。

**目标**：做一个"万能视频下载网站"，更快速、随时随地（电脑 + 手机浏览器）、从各个平台下载视频，并提供视频总结、字幕翻译等增值能力，具备付费转化的产品形态。

**定位**：学习项目，重点是体验"站在开源巨人肩膀上 + AI 辅助开发"的新开发模式。尊重版权，提示封号/风控风险。

## 2. 关键决策（已与需求方确认）
| 问题 | 结论 |
|---|---|
| 前端风格 | 以吸引付费为导向，突出实用价值；模仿 https://www.anytocopy.com/ 的 UI 风格，但要有辨识度 |
| 前端技术 | Vue3 + Vite，前后端分离 |
| 是否需要后端 | 需要，但尽量轻量，**不使用数据库**（v1.5 起账号与登录会话使用 MySQL，任务仍为内存模型） |
| 如何下载视频 | 不自研解析，直接封装开源项目 **yt-dlp**（GitHub 15 万+ Star，支持 1800+ 站点），不修改其源码 |
| 抖音 | yt-dlp 的抖音提取器需要浏览器签名 Cookie 且无法自动生成 → 抖音链接改用 **Johnserf-Seed/f2**（Python 库，开源 a_bogus 签名算法）封装，同样不改源码 |
| 技术栈 | 以 Python 为主（与 yt-dlp 一致） |
| 交付方式 | 两者结合：可用的免鉴权单文件直链 → 前端直链秒下；否则服务器下载/合并后中转 |
| Cookie / 登录态 | **不使用任何账号 Cookie**，只下载公开内容（降低封号与合规风险）；例外：抖音使用程序自动生成的**匿名访客 Cookie**（ttwid + msToken），不关联任何账号 |
| AI 服务 | DeepSeek（OpenAI 兼容协议，可替换） |
| 付费 | 一期**只做定价页展示**与 UI 引导，不做额度限制、不接真实支付 |

## 4. 功能需求（一期范围）
### F1 解析与单条下载
- 粘贴链接或**含链接的分享口令**（自动提取 URL）。
- 展示封面、标题、作者、时长、播放量、平台、可选清晰度（含预估大小）、字幕列表。
- 三种模式：视频 MP4（选清晰度，音视频自动合并）/ 音频 MP3（192kbps）/ 字幕 SRT（选语言）。
- 下载进度实时展示（百分比、速度、剩余时间、合并转码状态）。
- 有可用直链时提供"直链秒下"（不经服务器）。
- 解析失败给出友好中文提示（不支持、需登录、私密、地区限制、超时、链接无效等）。

### F2 批量下载 + ZIP
- 一次粘贴多条链接（多行或混合文本），自动去重，上限 20 条（可配置）。
- 后台逐条下载，单条失败不影响其他，展示每条状态；完成后打包 ZIP 下载。

### F3 字幕下载
- 2026-11-08 修正字幕查询：元信息解析显式启用 yt-dlp 人工及自动字幕查询；此前 B 站提取器会直接跳过字幕。平台明确要求登录时提示“字幕需要登录”，不能断言视频没有字幕。仍不使用账号 Cookie，可由用户另行点击音频转文字。
- 2026-11-08 补充：B 站 player 接口匿名返回“字幕需登录”时，改用匿名 `x/v2/dm/view` 接口兜底取原语言轨道（人工 + 原语言自动字幕，不含机器翻译轨道），不使用 Cookie；兜底失败才提示需要登录。样本 BV1mAAmzqEfP 已实测可下载。
- 支持平台字幕与自动字幕（自动字幕仅保留常用语言与 `*-orig`），统一转为 SRT。

### F4 AI 视频总结
- 基于字幕（优先中文 → 英文 → 其他；平台字幕优先于自动字幕），调用大模型，**流式**输出 Markdown：一句话总结、核心要点（带时间戳）、详细大纲、金句。
- 未配置 Key 时降级提示"未启用"；无字幕时提示不支持。

### F5 AI 字幕翻译
- 将字幕翻译为目标语言（简中/English/日本語/한국어），生成**双语 SRT** 文件下载，展示翻译进度。

### F6 定价页与付费引导
- 三档方案（免费 / Pro 月卡 / Pro 年卡"最受欢迎"），划线原价、折合每日价、当日倒计时、权益对比表、购买 FAQ。
- 全站 PRO 角标（4K/1080P、批量、AI）、导航"升级 Pro"、手机底部可关闭的升级条。
- 点击购买 → 弹窗说明"演示版，支付即将上线，当前全部免费"；v1.5 起导航「登录」「注册」打开真实的登录/注册弹窗。

### F7 抖音视频下载（v1.1）
- 支持抖音分享口令、`v.douyin.com` 短链、`douyin.com/video/<id>`、`?modal_id=<id>` 等链接。
- 解析展示封面、文案（作为标题）、作者、时长；清晰度固定为"原画·最佳画质"（无水印播放地址）。
- 支持 MP4 下载（服务器中转，带进度）、MP3（ffmpeg 转码）、直链秒下、批量下载混合抖音与其他平台。
- 不支持：图文/图集作品（提示"暂不支持图文"）、字幕与 AI 总结（抖音无字幕，提示明确原因）。
- 错误提示：作品删除/私密、链接无法识别、超时、接口失效（平台更新）。

### F8 视频转文字（v1.2）
- 2026-11-08 用户确认速度优先，默认已切换 `fun-asr-flash-2026-06-15`，只需百炼 Key。超过 5 分钟按连续 280 秒采样范围分段，默认每视频并发两段，按原顺序及采样偏移合并。保持整条 60 分钟/100MB 上限；单价估算 0.00022 元/秒，逐段向上取整。100 项非网络测试通过；部分失败不重复收费识别，未决提交保留预占供核对。下述实时方案为此前实施记录，最新行为以本条及配置指南为准。
- 单条链接的现有结果卡片中自动读取平台字幕，保留人工轨道优先、组内语言优先的规则，前后端统一默认语言。
- 2026-11-08 用户决策变更：确认“没有字幕/字幕为空”（`NO_SUBTITLES`/`EMPTY_SUBTITLES`）时，前端自动发起音频转文字，无需再点击；字幕访问的网络/鉴权失败仍不自动转收费识别；ASR 未启用时不发起；预算、限速、并发和同一视频去重规则不变。显式按钮保留为失败后的重试入口。
- 没有字幕或字幕内容为空时，后台复核后调用转写（此前为用户显式点击“音频转文字”）；字幕访问失败不自动转收费识别。
- 从视频实际音轨识别原语音，不使用背景音乐预览地址，不做 OCR、自动翻译或文本润色。
- 输出来源、原文、时间戳、复制、TXT/SRT；同一结果的操作及重复请求不重复提交云识别。
- 默认只需百炼 API Key，经 WebSocket 直接发送音频；使用独立任务队列、匿名会话隔离、容量/速率限制、预算预占账本。默认并发 2、等待 20、单音频 60 分钟/100MB、每日预估 10 元，首次实测预估不超过 5 元；实时估算单价为 0.00024 元/秒。
- 本期保留单进程；结果从结束起保留 30 分钟。本地音轨终态删除；实时连接状态不明时保留预占，不自动重发，需管理员核对。旧文件识别及 OSS 适配器保留为可选扩展。
- 首期不增加本地上传、批量转写、说话人分离或无字幕视频的总结/翻译联动。真实识别准确性、时间轴与云端输入清理需配置后验收。

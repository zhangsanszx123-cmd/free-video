## 交付内容

- `/account/api`：密钥创建、一次性完整展示、复制、列表、撤销和会员资格说明。
- `/account/api/docs`：公开接入文档、视频/封面直链限制、接口字段、幂等、状态错误、额度、示例下载。
- `/api/open/v1`：异步提交、状态和结果查询、TXT/SRT 导出、共享额度查询；独立 Bearer 凭据与 API 任务授权。
- `/api/openapi.json`：只包含开放接口的 Schema，含模型、Bearer 和必填幂等头。
- [最终契约](./open-api.md)、[已确认方案](./open-api-plan.md)、Python 和 Node.js 可运行示例。

最终专项覆盖：

- 凭据仅存摘要、网站 Cookie 不能冒充密钥、跨账号任务/密钥不可访问、内部网页 ID 不可作为 API task_id。
- 会员权限、三把密钥上限、到期保留已受理查询、撤销/改密/找回后凭据失效及旧密码快照不能复活。
- 同账号并发同键只入队一次，同键异参 409，多密钥合计频率与并发，别名按实际目标计数。
- 平台字幕不扣量，ASR 只结算一次、低余额阻止供应商提交，unknown 冻结且禁止整条重发。
- 视频/封面字段、TXT/SRT、数据库恢复媒体元信息、别名目标从 SQL 恢复、非就绪导出返回 409。
- 入队前后崩溃窗口、线程池拒绝、未知异常内容不泄漏、数据库短暂中断后的未入队授权在后续请求中核对，不需重启且不自动重发。
- 私有地址/伪造平台域名/凭据 URL/异常端口、短链重定向至内网、DNS 多地址含内网均拒绝，交给提取器的参数只保留 ID 和必要分 P。

## 用户人工验收

1. 打开 `http://127.0.0.1:8000/account/api/docs`，无需登录可阅读，确认接口、价格/额度、视频和封面地址有效期说明。
2. 使用现有有效月卡或年卡账号登录，打开 `/account/api`，创建一把测试密钥。保存后关闭展示、刷新页面，应仅看到前缀。
3. 下载任一调用示例，按 [接入文档](./open-api.md) 设置环境变量。先用有平台字幕的公开作品，保持 FREEVIDEO_ALLOW_ASR=false；获取 task_id 后查询原文和 SRT，检查 source_url/video_url/cover_url。部分平台直链为空属于既定契约。
4. 如需验证语音识别，自己明确设置 FREEVIDEO_ALLOW_ASR=true，选择套餐时长内的短视频；这一步会实际使用账号识别额度。成功后重复同键提交与查询，应返回原任务且不再次扣量。
5. 撤销测试密钥，再用它查询应返回 API_KEY_INVALID / 401。需要继续使用时新建密钥，不必向开发者提供完整凭证。
6. 手机宽度查看文档和密钥页面，确认阅读、复制与撤销操作可用；反馈具体页面和错误码即可。

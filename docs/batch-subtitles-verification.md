## ZIP 下载与默认入口修订

当前最终方案：下载前只查询 JSON 任务状态，文件本身交给浏览器或 IDM 原生下载。用户截图显示 IDM 接管了 ZIP 请求，而前端读取 ZIP 正文会触发异常校验；因此移除 ZIP fetch、分段预检和签名检查，不要求用户重复提取。准备状态和任务过期等错误提示保留，文件传输失败由浏览器/下载器显示。

字幕已设为第一项和默认模式。新增字幕/视频 ZIP 的过期错误可见、失败后重试下载测试，浏览器测试更新为 3 + 7 组。

实际文件验证：25,133,709 字节视频 ZIP 与 14,230,951 字节双音频 ZIP 均已检查 CRC 完整。独立 Chromium 的原生下载已成功保存 25MB ZIP 并校验内容；此测试不包含用户 Chrome 的 IDM 扩展。用户 Chrome/IDM 环境的最终接管和保存仍需用户验收，不能把独立浏览器结果等同于该环境验证通过。测试没有重新下载平台视频或调用收费识别。

浏览器模拟测试检查下载链接交接、JSON 过期错误和重试，且专门禁止用 fetch 访问文件路由；不把模拟路由的下载事件视为真实文件传输完成。菜单加入「批量提取 PRO」，位于「AI 总结」之后；首页选项卡去重边框，批量横幅采用深紫渐变、淡点阵和圆弧。

## 自动化验证

后端新增 `backend/tests/test_batch_transcriptions.py`，覆盖：

- 平台字幕不调用 ASR，部分失败继续，重复链接去重。
- 无字幕调用已有收费队列；重复批次提交、预览和 ZIP 不再次识别。
- 登录限制不转收费；预算不足不提交云端；全部失败不下载空 ZIP。
- 结果与 ZIP 的会话隔离、跨站来源校验、条数/付费参数校验。
- 未结束时拒绝打包、终态 ZIP 内容/文件名以及批次过期。

前端新增 `frontend/tests/batch_subtitles_ui.py`，以模拟接口检查：

- 空态、逐条阶段、成功/失败预览、时间戳切换。
- 防重复点击；未结束禁用 ZIP，结束后可下载 ZIP 与单条 SRT。
- 刷新恢复不重新 POST；过期提示与本地记录清除。
- 桌面和 390px 手机布局、页面横向溢出、未捕获 JavaScript 异常。

执行命令（项目根目录，浏览器测试需先启动 Vite 5178）：

```powershell
cd backend
.venv/Scripts/python -m pytest
cd ..
npm run build --prefix frontend
python -P frontend/tests/ui_regression.py
python -P frontend/tests/batch_subtitles_ui.py
```

浏览器测试使用现有 Python Playwright 环境；全部新增自动化使用模拟云端服务，不产生真实识别费用。

## 人工验收

1. 重启后端加载新 API，打开 `/batch`，选择「字幕 SRT · 支持语音识别」。
2. 输入一条有平台字幕、一条无字幕和一条无效链接，确认按钮上方有收费说明，然后开始提取。无字幕样本会按现有配置产生真实费用。
3. 查看检查字幕、获取音轨、识别阶段；已成功项可立即展开，失败项显示原因。全文和时间戳切换、复制与单条 SRT 下载可用。
4. 全部结束后点击打包，确认 ZIP 只含成功结果、文件不重名、字幕时间轴可用。
5. 处理中离开再返回或刷新页面，确认恢复同一批次，没有重复提交；浏览器会话和服务进程必须保持有效。
6. 手机检查列表、预览和导出按钮；工作台不显示底部升级浮层。

本次实现保留单进程无数据库架构。批次正文在进程重启后不可恢复；相同链接整批结果在有效期内复用，包括失败项。未决/部分识别失败沿用现有保护，不自动重新发送收费音轨。真实云端效果待用户验收。

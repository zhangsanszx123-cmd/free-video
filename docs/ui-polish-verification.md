## 浏览器回归

使用已有 Python Playwright 环境与 Chromium。先在 `frontend` 启动：

```powershell
npm run dev -- --host 127.0.0.1 --port 5178 --strictPort
```

然后在项目根目录执行：

```powershell
$env:PYTHONIOENCODING='utf-8'
python -P frontend/tests/ui_regression.py
```

测试完全模拟 API，不下载真实视频，不调用 AI 或收费转写。

- 首页、学习工作台：延迟解析响应，清空后旧结果不重新出现。
- 视频、音频、批量与翻译：同一事件循环连续点击只提交一次；请求未返回前按钮锁定，失败后恢复且显示错误。
- 首页健康接口返回 503 时显示连接失败。
- 弹窗：初始焦点在弹窗内，连续 Tab 不逃逸，Esc 关闭后焦点回到触发按钮，恢复页面滚动。
- 手机 390×844：首页、学习工作台、批量、旧 AI 工具、定价页无页面横向溢出；关闭升级提示按钮至少 44×44，关闭后释放底部留白。
- 页面未捕获 JavaScript 异常检查。

## 人工验收

1. 首页或 `/learn` 输入链接，立即解析后快速清空，确认结果不会重新出现。换一个链接重试应正常。
2. 连续点击下载视频、音频、批量下载、生成双语字幕，确认按钮立即锁定，失败后能够重试。
3. 首页服务状态应与后端连接情况一致；状态每 30 秒刷新，超时最多等待 5 秒。
4. 桌面点击登录打开升级弹窗，使用 Tab、Shift+Tab、Esc 检查焦点与关闭后的恢复。
5. 手机检查首页和学习工作台，滚动到底部，确认升级条不遮住页脚内容；关闭升级条后底部空间收起。

真实平台解析、下载与云端 AI 输出质量未包含在本次模拟浏览器回归中。服务器已接收的任务不会因关闭页面而取消；提交锁用于阻止同一页面的重复点击，不提供跨标签页的后端幂等保证。

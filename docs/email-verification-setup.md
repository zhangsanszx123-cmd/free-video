# 163 邮箱链接验证：本机测试

当前已启用，入口：[本机注册](http://localhost:8000/register)。请在运行网站的电脑上使用；手机中的 localhost 指向手机，无法打开电脑网站。

最新界面：账号弹窗为「登录 / 注册 / 找回密码」。注册只填邮箱、密码和算术图形验证码，点击图片刷新；登录与重发邮件只填邮箱密码，不需要图形验证码。

## 配置

后端 `.env`（已被 Git 忽略）使用以下键，授权码不能提交或放到前端：

```dotenv
AUTH_EMAIL_VERIFICATION_REQUIRED=true
PUBLIC_BASE_URL=http://localhost:8000
SMTP_HOST=smtp.163.com
SMTP_PORT=465
SMTP_SSL=true
SMTP_USER=你的163邮箱
SMTP_PASSWORD=邮箱SMTP授权码
SMTP_FROM=你的163邮箱
```

变更后重启后端。`false` 仅关闭新注册的验证要求，不会自动激活既有待验证账号。正式部署需将 PUBLIC_BASE_URL 改为用户可访问的 HTTPS 网站地址。

## 验收

1. 打开本机注册页，填写可收邮件的邮箱、密码与图形验证码。
2. 页面应提示验证邮件已发送，此时仍未登录；不要关闭原操作页面也可在另一标签页验证。
3. 去邮箱查收「验证你的 FreeVideo 注册邮箱」，找不到时检查垃圾邮件。
4. 在这台电脑打开邮件链接，点击「确认验证并登录」，页面显示成功；回到原标签页应同步登录。
5. 同一个链接再次使用应提示无效；超过 30 分钟也无效。未验证账号可在登录失败提示后，用原注册邮箱和密码重发，不需要图形验证码。
6. 重发须间隔 60 秒；新邮件发送后旧链接失效。邮件发送异常不会绕过验证，也不会自动重发。

待验证账号保留原密码，不能通过重发验证邮件接口更换密码；忘记原密码时使用弹窗的「找回密码」，重置邮件可同时完成邮箱验证。详见[找回密码验收](./password-recovery-verification.md)。邮箱验证不能保证一人一号。

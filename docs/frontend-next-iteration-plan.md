## 1. 当前项目理解

已阅读 `requirements.md`、`design.md` 及相关方案和验收记录，并交叉核对前后端代码与测试。文档以最新确认条款覆盖旧版本记录。

- 前端为 Vue 3、Vue Router、Vite、Tailwind，视觉 token 集中在 `frontend/src/style.css`，内容数据在 `data.js`。首页解析结果由 `ResultCard` 展示，AI 精读组件同时供首页和 `/learn` 工作台使用；旧 `/ai` 总结与翻译入口继续保留。
- FastAPI 托管接口与生产前端；`downloader.py` 统一封装 yt-dlp，抖音分流至 f2。下载、翻译走内存任务和轮询，AI 总结和追问走 SSE。
- MySQL 保存账号、会员、额度、支付与字幕/识别历史；下载等媒体任务仍为单进程内存任务。用户额度与供应商 ASR 成本账本分别结算，识别状态不明只查询原任务，不重新提交。
- 游客仅可解析和下载两个不同链接，Cookie 与 IP 共同限制；批量、字幕、AI、ASR 等操作需要登录。`/batch`、`/ai`、`/learn` 可先浏览，执行时打开登录窗；个人中心、历史和支付结果页有路由守卫。
- 登录为邮箱和密码；注册另需算术图片验证码及按当前配置执行邮件验证。套餐按个人周期计算，价格、时长与功能上限读取服务端配置。
- 支付仅为支付宝页面跳转，微信不可选；站内二维码尚待确认。此前明确保留的结果卡占位入口，以及暂缓的手机触控区扩展，继续按已有决定处理。

## 2. 本轮确认范围：三项前端交互修复

### A1：旧请求的登录失效响应会清掉新会话

**现象与证据**：A 身份发起请求并等待响应，随后登录 B；A 的旧请求返回 `401 / AUTH_REQUIRED` 后，B 被错误置为游客。纯 Node 内存替身已复现五个入口：`accountApi.history`、`api.transcript`、`downloadArchive`、`streamLearnSSE`、`learnApi.mindmap`。实际状态从 `authed / id=2` 变为 `guest`。

**涉及位置**：`frontend/src/account.js:30`、`frontend/src/api.js:16`、`frontend/src/api.js:83`、`frontend/src/learning/learnApi.js:17`、`frontend/src/learning/learnApi.js:79`。

**设计**：集中管理请求所对应的会话版本，各请求在发送时捕获版本，只有仍对应当前会话的登录失效响应才能清除身份。需要覆盖同账号重新登录；仅比较用户 ID 或现有页面重建版本不足以实现此保护。普通资料刷新与真正的会话切换应区分，保留当前会话正常过期时的重新登录提示。

**验证**：补充上述五个入口的旧 401、新账号登录、同账号重新登录、当前会话真实过期测试；继续验证跨标签同步、路由回跳和原有账号竞态用例。

### A2：首页分享链接初始化会覆盖用户后续输入和模式

**复现**：打开 `/?view=ai&url=A`，延迟 `/api/auth/me`；用户输入 B 并切至下载模式，随后释放登录响应。模拟浏览器实际观察到输入恢复为 A、AI 选项卡重新选中，解析请求先后为 B、A。

**涉及位置**：`frontend/src/pages/Home.vue:37` 的挂载初始化。在等待身份检查后，没有复核操作版本，未覆盖已有 `aiAllowed` 的防竞态保护。

**设计**：分享链接初始化也绑定当前操作版本与组件存活状态。用户编辑、清空、切换模式或离页后，旧初始化不再写入输入、选择模式或提交任务；没有后续操作时保留正常的分享链接自动解析和游客降级行为。

**验证**：在桌面与 390px 下覆盖延迟身份查询、编辑输入、清空、切换模式、离页，以及正常打开分享链接。

### A3：B站分 P 预览遗漏选集信息

**证据**：模拟解析返回 `https://www.bilibili.com/video/BV1mAAmzqEfP/?p=2`，首页和工作台实际生成的 iframe URL 都仅包含 bvid、画质、弹幕、自动播放及时间参数，没有选集参数。后端字幕链路按分 P 提取，存在预览与文稿不对应的风险。

**涉及位置**：`frontend/src/components/ResultCard.vue:106`、`frontend/src/learning/pages/LearnWorkbench.vue:43`。两处分别拼接同类播放器 URL。

**设计**：共用 B站播放器 URL 构造工具，将所选分 P 映射到播放器支持的选集参数，保留时间戳与自动播放设置。默认第一 P、异常选集参数及原平台跳转保持可预测行为。

**验证**：覆盖默认/P2/P3、非法选集、首页与工作台两入口，以及时间戳跳播时仍保留选集。当前已验证 URL 遗漏，没有调用真实平台播放器；实际分 P 播放需后续真实平台验收。

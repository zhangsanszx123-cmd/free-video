# Fun-ASR-Flash 完整性误判修复与验证

日期：2026-11-13。

## 问题与修复

公开视频 `BV1TkxJ6iEGk` 在提取文稿时显示识别状态待核对。一次用户授权的真实诊断请求获得 HTTP 200 与有效 SSE 文字响应，本地音轨 109.017688 秒，API 累计处理用量 `usage.duration` 为 98 秒。

旧代码将用量低于本地音轨时长视为结果不完整，抛出 `CLOUD_NETWORK`，继而保留用户额度预占。该等值假设没有接口协议依据。修复后不再用两者差值判断成功或失败；仍要求 HTTP 流正常结束、末句为最终结果、累计文字与句子一致、词级时间轴有效。

供应商用量按 API 返回值记账，用户额度仍按服务端核实的实际音轨时长向上取整，两者独立。真正的连接中断、未完成句、空响应和无效时间轴继续拦截；不自动重发收费识别。

依据：[官方 Flash HTTP API](https://help.aliyun.com/en/model-studio/fun-asr-flash-recorded-speech-recognition-http-api)。

该操作不代表旧云端请求已经查证成功；旧请求的供应商成本记录仍保留 unknown，等待人工核对，不能用独立诊断的用量冒充旧请求的真实用量。

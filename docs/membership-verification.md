# 会员额度与历史任务验收

日期：2026-11-11。环境：Windows、MySQL 8.4、Python Playwright/Chromium。

## 已实现范围

- 免费每月 30 分钟；月卡 19.9 元/每月 10 小时；年卡 99 元/每月 30 小时。所有套餐按北京时间每月 1 日重置。
- 仅 ASR 语音识别扣时长，使用服务端核实音频的整秒时长；平台现成字幕和视频下载不扣量。
- 套餐配置入库；人工开通时保存权益快照；提供本机命令供运维配置，尚无支付与后台页面。
- 账号菜单和个人中心展示会员、已用/预占/剩余额度。执行中及历史任务按账号隔离，记录和正文保留 30 天。
- 状态明确失败释放用户时长；不确定提交保留预占，不自动再次发送音轨。供应商成本账本与用户额度分开处理。

## 验证方式

所有数据库测试使用 `MYSQL_TEST_DATABASE=freevideo_test`，媒体与 ASR 使用模拟数据；页面测试后端设为测试库，AI/ASR Key 为空。没有实际付款、媒体下载或云识别费用。

- 前端：`npm --prefix frontend run build`。
- 后端：在 `backend` 运行 `.venv/Scripts/python -m pytest -m 'not network' -q`。
- 会员数据库测试：`tests/test_membership.py` 共 20 项。
- 页面：`python -P frontend/tests/membership_ui.py`（5 项）；`account_ui.py`（9 项）；Vite :5178 下 `ui_regression.py`（7 项）、`batch_subtitles_ui.py`（3 项）。

会员页面测试后端的启动环境和账号 UI 测试一致，见 [账号验收](./account-verification.md)。会员 UI 测试中的固定历史记录只写入 `freevideo_test`，脚本有数据库名断言。

## 人工验收（待用户）

- [ ] 登录，打开昵称菜单：查看免费会员剩余额度，进入「执行中任务」「历史任务」。
- [ ] 个人中心切换「会员与额度」，确认总时长、已用、预占、剩余及北京时间重置时间。
- [ ] 查看 `/pricing`，核对三档价格及每月额度；点击开通只显示未开放支付说明。
- [ ] 提取有平台字幕的视频：历史出现文稿，额度不减少。
- [ ] 在配置并允许消耗识别费用后，用短视频验证 ASR 成功扣除实际音轨秒数；再次打开已有结果、复制、导出不重复扣量。
- [ ] 另一浏览器登录同一账号能看到历史，移出历史不返还已使用额度。
- [ ] 手机查看会员面板和历史文稿，确认可读性及按钮操作。

## 运维与限制

套餐配置和人工开通命令见 [实施方案](./membership-quota-plan.md)。本期维持单进程队列；只持久化转录任务历史，不恢复中断任务的自动执行，不保存下载视频/音频。不要同时用多个服务进程共用同一生产队列和成本状态目录。

待核对请求不会因删除历史或进入新月份自动释放。管理员需根据供应商实际状态核对；不确定时不自动重发，防止再次产生费用。

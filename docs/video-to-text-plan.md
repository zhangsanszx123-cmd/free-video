# 视频转文字：已确认方案与实施状态

2026-11-08 最新修订：用户确认速度优先，默认及本机配置已切换 **fun-asr-flash-2026-06-15**，只需百炼 Key。超过 5 分钟自动分为连续 280 秒 WAV、默认两段并发，按采样偏移合并时间轴。保持整条 60 分钟/100MB 上限，逐段预占及结算，未决不自动重发，部分失败禁止整条重复收费。100 项非网络测试及前端构建通过；正式页面 4 分 47 秒视频任务完成耗时 22.805 秒。最新操作见[配置指南](./video-to-text-setup.md)，证据见[快速验证](./video-to-text-fast-validation.md)。以下实时方案为此前实施记录，不再是默认。

依据：[需求](./requirements.md)、[架构](./design.md)、[原选型调研](./video-to-text-research.md)。操作见[配置与验收指南](./video-to-text-setup.md)。

## 1. 已确认范围

- 平台可下载字幕优先（含自动字幕），无可用字幕时用户点击“音频转文字”。
- 仅现有单条视频链接入口；不新增本地上传、批量转写或画面硬字幕 OCR。
- 允许音频发往第三方云服务并按量付费；用户只需提供百炼 Key，不要求开通 OSS 或提供 AccessKey。
- 默认模型为 `paraformer-realtime-v2`，后端通过 WebSocket 直接发送视频音轨，不依赖公网音频 URL。
- 原文、来源、时间戳、复制、TXT 和 SRT；不使用文本大模型润色，也不把字幕语言选择当作付费翻译指令。
- AI 总结/翻译联动后续实施；本期仍按原有平台字幕语义工作。
- 服务器多人使用，单进程，无数据库、Redis、账号或真实支付，不自动部署公网。

## 2. 实施流程

1. 解析并检查字幕，人工轨道优先，各组内按语言选择；前后端使用统一默认值。
2. 下载并解析可用字幕，直接显示正文和时间轴，ASR 次数为 0。网络/鉴权/下载失败不能自动当作无字幕。
3. 没有轨道或轨道为空时，由用户明确触发识别；检查会话、容量、配置与资源限制。
4. 复核视频元信息，提取真实音轨（抖音不能使用背景音乐预览 URL），ffprobe 检查时长、音轨、转换后的 MP3 大小。
5. 本地转成单声道 16kHz/16bit PCM。预占预算后用 Key 建立加密 WebSocket，写账本后发启动指令，等待 task-started，再分帧发送声音，同时接收结果。
6. 只采纳最终句子，忽略中间结果/心跳。时间戳为空时只允许使用实际返回的词级结束时间，不能按文本长度推算。
7. 发送完成指令，收到 task-finished 才生成完整结果。统一生成 TXT/SRT，优先按累计云端 usage 结算，删除本地音轨。

实时发送耗时与音频长度有关，不承诺长音频秒出结果。识别中断时不把部分文稿冒充完整成功。

## 3. 接口与扩展

- 保留 `/api/transcript` 的平台字幕语义，返回来源、语言、正文、时间戳和 SRT。
- `GET /api/transcription-session` 建立签名匿名会话；`POST /api/transcriptions` 创建任务，`allow_asr` 默认 false。
- `/api/transcriptions/{id}` 与 `/file?format=txt|srt` 必须校验任务拥有者，不经旧的无授权通用文件路由。
- `asr.py` 为服务商注册表；实时适配器实现 `configured`、`recognize(pcm,on_submit,cancel)`，文件适配器实现 `configured`、`submit(url)`、`query(id)`；统一返回 Recognition/Cue。
- `transcriptions.py` 复用字幕、队列、预算、导出，默认实时路径不会实例化 OSS 存储。原 `paraformer-v2` + 私有 OSS 是可选文件适配器。
- 前端切换页面或语言时停止旧请求、忽略旧响应；轮询断开只重试查询，不新建收费任务。

## 4. 资源与费用控制

| 项目 | 默认值 |
|---|---|
| 压缩识别音轨 | ≤60 分钟、≤100MB，均可配置 |
| 并发／等待 | 2／20，独立于下载线程池 |
| 创建速率 | 同会话及直连 IP 每分钟 10 次 |
| 本地文稿 | 成功或失败结束后保留 30 分钟 |
| 实时识别超时 | 3900 秒，预留一小时音轨发送后的收尾时间 |
| 全站日估算额度 | 10 元；首次真实实测预估不超过 5 元 |
| 实时预算单价 | 0.00024 元/秒（北京），约 0.864 元/小时，不扣免费额度 |

原文件模型价格 0.00008 元/秒不用于实时模型。应用预算不是实时云账单，以控制台为准。PCM 是本地解码中间文件，可大于压缩源大小，最长一小时约 115.2MB；分帧发送，结束后删除。

去重键包括会话、规范视频 URL 与识别参数；同一结果的复制、导出、重复点击、分享链接别名和空字幕语言切换不重复识别，不跨用户返回结果。

账本采用进程内锁、fsync 与原子替换，记录日期、预占、结算、传输类型、云端/客户端任务 ID 和必要的旧对象标识，不保存正文或 Key。坏账本暂停新的收费提交，未决预占跨日保留。

## 5. 中断与恢复边界

- 实时连接鉴权失败或启动前失败，释放预占；服务端明确结束，按已知用量或预占结算。
- 实时启动后断线/超时/重启，保留预占，不自动重发声音。客户端 UUID 不可用文件任务接口查询，本期没有流式断点恢复，需管理员核对云端用量。
- 重启不会恢复完整任务页面或正文；能保留实时未决费用记录，避免忘记预占后再次收费。
- 可选旧文件任务仍按原方案后台查询、结算、删除 OSS 输入；配置环境变化时不误操作旧桶。文件适配器需配置私有桶和生命周期兜底。
- 新转写任务会话隔离不代表存量下载接口已改造成账号授权接口。生产仍需 HTTPS、稳定会话密钥及可信代理配置。
